Viewing the Rock World

Welcome to the Viewing the Rock World outreach project!

Viewing the Rock World is based on a 3D printed thin section viewer that can easily be made by anyone with a 3D printer for under $5CAD. On these pages, you will find all the information relating to the project and how you can be a part of it.

This project is no longer in a “get involved” phase, so there’s no traveling thin section collection to join. At this point, participants simply 3D print the viewer themselves to keep it alive. I’m still thrilled to hear about people building and using it, so if you print one, please get in touch and let me know how it went. I love receiving updates.

As this project develops, I will create more content and fill out these pages. If you have any questions or need help, don’t hesitate to reach out!

Check out the project’s YouTube channel for instructions and additional information.
